# 🧮 Calculadora en Python

Calculadora de consola desarrollada en Python como proyecto práctico
para aplicar conceptos fundamentales del lenguaje.

## 📌 Descripción

Este proyecto permite realizar operaciones matemáticas básicas:

- Suma
- Resta
- Multiplicación
- División

También incluye manejo de excepciones para evitar errores cuando:

- El usuario ingresa un valor que no es numérico.
- Se intenta realizar una división por cero.

El proyecto cuenta además con pruebas automatizadas utilizando `pytest`.

## 🚀 Tecnologías utilizadas

- Python 3
- Pytest
- Git
- GitHub
